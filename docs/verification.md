## 自动验证

九项 Go 测试覆盖下列行为，其中流式适配分别验证 Ollama 与兼容接口：

- 早期阶段不读取未来人物能力，物品可继承历史版本，章节显式排除生效。
- 请求上下文包含当前有效设定，超过窗口预算时阻止发送。
- 独立项目不串正文，旧 revision 写入被拒绝，保存后可读取并恢复历史。
- 同一 revision 的两个并发写入只有一个成功。
- Ollama JSON 行流与兼容接口 SSE 流都能组装中文输出。
- 本地文风规则、重复标点、章内重复和重复阶段版本检查。
- 跨来源写入、缺失桌面会话令牌和非本机 Host 请求被拒绝。
- 检测接口请求与响应协议、短正文阻止、设置读取时密钥脱敏。
- 完整项目导出再导入保留正文并生成独立项目身份。
- AI 检索词规划后返回实际存在的正文段落，不将模型输出冒充来源。

另外验证了停止生成保留正文、正文改变后拒绝直接采纳旧候选，以及恢复历史后编辑器立即显示恢复的正文与字数。历史恢复曾发现编辑器显示未刷新，已修正为在载入项目快照时重新初始化编辑器，并在最终构建中复验通过。

## 尚未验证的外部服务

Brave 联网搜索未使用真实密钥调用，检测服务采用模拟响应验证协议。实际搜索质量、检测准确率与中文适用性取决于配置的服务。

当前本地检索不是向量检索，重复检测是精确段落匹配。AI 审稿与生成的一致性仍由作者核对，应用没有承诺不偏离或通过平台检测。
