# 功能完成状态（v0.4.2）

这是当前实现清单，最初设计文档中的扩展设想不等于已完成功能。

| 最初需求 | 当前状态 |
| --- | --- |
| 小说编写与字体 | 正文编辑、字体字号、选区字体、行距、缩进、主题、专注、字数和纯字数、查找替换、空白行清理、正文修改标记（说明/定位/处理/撤销）均可用 |
| 项目分开与切换 | 独立数据库、书架切换、章节/光标/滚动位置恢复、自动保存、冲突检查、项目历史、完整 JSON 备份与副本导入 |
| 大纲、细纲、故事线 | 独立页面、总览/卷纲、分卷阶段、章纲、多故事线及章节节点 |
| 分时期人物/物品/场景 | 基础档案、阶段版本、历史继承；人物常用字段可勾选 |
| 分卷阶段调用资料 | 卷/阶段资料集、章级增减、右侧卡片，JSON/CSV 导入映射、预览与同名处理 |
| 本地 AI 辅助 | Ollama/兼容服务、模型发现、容量读取、手填不限固定上限、完整上下文与预算、流式候选、改写对比、采纳/撤销/取消；需实际可用模型服务 |
| 文风、错字和 AI 检查 | 本地常见错字/标点、重复和文风规则，AI 审稿，独立来源检测适配。真实检测效果取决于服务；不以本地规则伪造 AI 来源分数 |
| AI 搜索片段与文风参考 | 本地关键词、向量语义、联网搜索、AI 规划检索词与文风分析；保留真实来源。灵感只有一个检索下拉框，无原创构思入口 |

新增导出支持 DOCX、EPUB，保留基本正文格式，EPUB 有章节目录。图片栏支持导入地图、人物和场景参考，AI 生成 SVG 自动入库，完整备份携带图片。AI 审稿与地图历史均保存到项目。

仍未实现的扩展：独立封面设置、章内场景独立故事时间与多时间线、图形人物关系、自动设定更新提案、章节单独历史回退，以及面向超大项目的持久向量索引和快照存储优化。它们不影响以上已经完成的主流程。

外部服务仍需实际配置：聊天模型、向量模型、AI 来源检测器。程序不会下载或捆绑大模型；测试夹具只用于协议和界面验证。
