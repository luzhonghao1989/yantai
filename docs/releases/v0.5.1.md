# Yantai v0.5.1

发布日期：2026-10-24。

## 服务端入口与部署

- 公网端口只接受 TLS 加密同步，不提供网页、登录页、模型配置或 Agent API；普通访问和无效认证返回空响应。
- 默认生成并持久保存私有证书，客户端可配置 SHA-256 证书指纹；也支持可信域名证书。拒绝明文同步、错误指纹和自动重定向。
- 独立内网 HTTP 工作台支持 `-web-listen` 与 `YANTAI_WEB_LISTEN`，绑定具体私网或回环 IP，共用服务端数据；网页保留访问密钥登录，不能映射公网。
- systemd 服务自动创建数据目录、设置目录及文件权限，部署文档补充更新服务、查看指纹和 Nginx 代理端口说明。

## 数据库异常与同步

- 单个不可读取项目保留在书架并显示错误与项目 ID，不再阻断其他小说。
- 同步分别标识本机/服务端异常及读取或写入阶段，异常项目停止上传下载，正常项目继续；不把异常项目当成删除，也不自动覆盖或修复受损原件。
- SQLite 引擎从 3.46.0 升级至 3.51.3，包含官方 WAL-reset 并发问题修复。这是预防修正，不能据此认定某次损坏的原因，升级也不会自动恢复已损坏文件。
- 服务端小说可读取、客户端没有独有内容时，先关闭故障客户端并备份整个实际数据目录，再运行新版重新配置同步并下载；有独有内容时先保留草稿和可导出项目。

## 升级与验证

关闭旧进程后替换程序，保留服务端 data、访问密钥及 TLS 证书。客户端与服务端建议一同更新；原 v0.5.0 标签保留不改。

源码构建最低 Go 1.25；发布程序无需安装 Go、Node.js 或独立数据库。客户端包不包含小说、密钥或本地设置。

自动回归与隔离联调见 [验证记录](../verification.md)，部署和恢复步骤见 [服务端说明](../server-sync.md)。


本机副本恢复补充：书架可删除本机项目；同步错误项可保留备份后从服务端重新下载。损坏数据库无需打开即可归档，同一项目的同步记录会重置，服务端副本保持不变。

图片管理补充（2026-10-25）：图片卡片和详情可确认删除；SVG 地图与 ComfyUI 生成结果也可直接删除。SVG 同时移除对应生成记录，ComfyUI 批量生成支持逐张删除。删除立即保存，随项目正常同步；已保存图片可通过项目历史恢复。
