# Yantai v0.5.3

发布日期：2026-10-29。

## 设置入口

打开软件后，书架右上角原“服务端同步”改为“设置”。无需打开小说即可配置同步项目、手动或定时同步、每日备份和恢复。服务端内网工作台也可从设置管理本机备份。

## 同步与删除

- 默认同步全部小说，也可勾选指定项目。列表合并本机和服务端小说，支持新电脑选择下载；空选表示不处理任何项目，手动和定时同步使用同一范围。
- 服务端书架删除项目前先备份，再永久记录删除状态，阻止旧客户端将同一项目重新传回。
- 客户端收到删除通知后，未修改副本先备份再移出书架；存在离线修改或没有同步基线时，提示保留独立项目或确认删除旧副本。未选择同步的项目不处理删除通知。

## 每日备份

- 客户端和服务端分别设置，默认开启、保留 30 天。启动时检查，运行期间每小时检查当天备份；停止期间不执行，下次启动补做当天备份。
- 支持立即备份、查看记录、恢复为新项目。包含已保存正文、富文本、批注、设定、AI 审稿和图片，不包含全局模型或同步密钥。
- 只有新备份全部成功后才清理过期成功备份；部分失败时保留旧备份。同步删除前也会创建可从备份页恢复的独立快照。
- 恢复创建新项目身份，不覆盖现稿或复活已删除的旧 ID。完整说明见 [备份与删除](../backups-and-deletion.md)。

## 章节标题

- AI 面板新增“生成标题”，默认根据正文、章纲和当前设定生成 6 个候选，可在要求中指定数量和风格，点击“用此标题”采纳。
- 保留原有章节编号；采纳前检查章节和上下文是否变化，仅修改标题。
- 正文顶部章节标题可以直接输入修改，自动保存并同步目录。

## 升级

关闭客户端，替换 Yantai.exe，保留原 data 目录。服务端停止服务后替换 Yantai-server 可执行文件，再启动；保留数据目录、访问密钥和证书，无需更改 systemd 或端口参数。客户端和服务端应同时更新。

服务端删除请使用书架按钮，直接移除磁盘目录不会生成删除记录。公网 TLS 同步端口继续不提供管理页面，备份和删除通过登录后的内网 HTTP 工作台操作。
