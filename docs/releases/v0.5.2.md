# Yantai v0.5.2

发布日期：2026-10-26。

## 正文导航

- 打开小说恢复上次章节、切换章节、返回正文或退出专注模式时，左侧目录自动展开当前卷，并将高亮章节滚动到可见位置。
- 正文状态栏在“Ctrl + S 保存 / Ctrl + Z 撤销”右侧提供“返回顶部”，保留正文和光标位置；支持较窄窗口换行。

## 图片管理

- 图片库卡片、详情、SVG 地图与 ComfyUI 生成结果都可确认删除，同批生成的图片支持逐张删除。
- 删除 SVG 时同步移除对应地图生成记录。删除随项目保存和同步，已保存图片可从项目历史恢复。

## 并发保存与草稿恢复

- 窗口与 Agent API 同时编辑时，以最后确认的数据库版本比较，合并不同位置的修改；删图与 API 修改正文可同时保留。
- 同一处修改、删除与编辑、顺序或关联冲突时暂停自动保存，显示位置，可另存独立草稿副本后返回书架或读取最新内容。
- 过期恢复草稿另存副本，保留 API 最新项目；异步处理期间出现的新编辑继续保留并提示。

## 本机项目恢复

- 书架支持删除本机项目副本；本机读取异常的同步项支持保留备份后从服务端重新下载。
- 本机数据库、WAL/SHM、历史和未保存草稿先归档，服务端项目保持不变；重置所选项目同步基线，避免旧记录阻止重新下载。

## 升级

关闭旧程序后替换可执行文件，保留现有 data、同步密钥和 TLS 证书。若旧窗口仍有保存冲突，先使用“导出 → 导出当前草稿”留存，再更新程序。

发布包包含 Windows 桌面/浏览器版、Windows Server 和 Linux amd64 服务端。客户端显示版本与 Windows 文件版本均为 0.5.2；服务端继续使用 TLS 同步与可选内网 HTTP 工作台。已有历史标签保持不变。

验证记录见 [verification.md](../verification.md)，部署说明见 [server-sync.md](../server-sync.md)。
