# Yantai v0.5.0

发布日期：2026-10-24。

## 服务端与多设备同步

- 新增 Linux amd64 与 Windows Server amd64 服务端，公网仅提供 TLS 加密同步接口，支持访问密钥认证、证书指纹核验和 Linux systemd 部署；网页工作台可选在独立内网 HTTP 端口开启。
- Yantai.exe 的模型与设置、书架提供服务端同步入口，配置服务端地址与密钥后可手动同步或按分钟定时同步。定时同步需要客户端保持运行。
- 同步完整小说项目、设定、AI 记录和图片，保留项目 ID；模型密钥、设备设置及各端已有历史不跨端复制。
- 单端修改自动同步；双方修改或首次同 ID 内容不同时提示冲突，由作者选择保留本机上传或使用服务端下载。选择后再次检查双方内容，避免覆盖后续修改。
- 替换前保存同步历史，删除不自动传播。当前为个人所有者多设备模式，以整个项目判断冲突，不自动合并段落。

部署说明见 [服务端部署与同步](../server-sync.md)。

## 写作与审稿

- 修复完整项目草稿超出 localStorage 配额导致的保存错误，改用 IndexedDB，兼容恢复旧草稿。
- 当前审稿和历史审稿支持一键替换全部有效建议；跳过无变化、过期、重复或同段冲突建议，整批替换可一次撤销。

## 升级

关闭旧版后运行新版 Yantai.exe，保留程序旁的 data 目录；服务端升级同样保留原数据目录。建议先导出完整项目备份。

发布包不包含小说、密钥或本地配置。客户端压缩包包含桌面与浏览器程序；服务端分别提供 Windows ZIP、Linux tar.gz 与部署说明。

自动检查与隔离联调记录见 [验证记录](../verification.md)。


## 同步数据库诊断补充

- SQLite 引擎升级至 3.51.3，包含官方 WAL-reset 并发问题修正；源码构建最低 Go 1.25，运行发布程序无需安装 Go。
- 书架保留不可读取项目及其 ID、错误信息，单个受损项目不再阻断整个项目列表和同步。
- 同步明确区分本机/服务端异常，异常项目停止上传下载，其他正常项目继续；不会把异常项目当成删除，也不会自动覆盖受损原件。已经损坏的库需要备份后从可用副本恢复，升级本身不修复文件。
