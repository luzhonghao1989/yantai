# 砚台 v0.5.4

发布日期：2026-11-02。

## 中文显示名称

窗口标题、浏览器标签、启动页、书架和工作台显示“砚台”，Windows 产品名称同步更新。程序文件继续使用 Yantai.exe / Yantai-server，沿用现有数据目录和同步协议。

## AI 审稿专项

- 对白生硬：检查报告腔、人物同一口吻、刻意解释双方已知信息、缺少人物动机的问答。
- 动作僵硬：检查重复插入小动作、动作与情绪或目标脱节、姿态/伤势/手中物品及空间位置衔接不合理。
- 机械化叙述：检查模板句式、对白动作之后重复解释、空泛评价或总结代替情节。
- 总结分别说明三个维度，具体修改意见标注问题类型，仍提供完整段落改文，并保留原文定位、逐段替换与一键替换。
- 根据人物、场景及项目文风判断，不以短句、标点或关键词直接判错，不机械补全口语，不为凑建议改变剧情事实。新增规则计入上下文估算。

更新后重新生成审稿才会应用新规则，已有审稿记录保持原样。

## AI 输入记忆

- 本机自动保存本章所选任务，按项目、章节和写作任务分别记住补充要求。
- 记住地图场景选择、灵感检索词与检索方式，以及 ComfyUI 画面要求、图片分类、种子和场景选择。
- 输入时保存，重新打开恢复；清空后的输入也保持为空。切换项目、章节和任务时使用对应输入，不将上一个页面的文字覆盖到新范围。
- 输入记忆属于当前电脑/浏览器的本地偏好，不随小说同步或项目备份迁移；模型连接配置仍在设置中保存。

## 升级

关闭旧客户端后替换程序，保留原 data 目录。服务端先停止服务，替换 Yantai-server 可执行文件，再启动；保留数据、密钥和证书，服务与端口参数无需改动。服务端页面与审稿规则由服务端程序提供，需要使用新版服务端。

此版本包含 v0.5.3 的无参数 JSON 请求修复，“立即备份”和“恢复为新项目”继续可用。
